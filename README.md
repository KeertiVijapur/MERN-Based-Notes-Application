# MERN-Based Notes Application

A **full-stack web application** built using the **MERN (MongoDB, Express, React, Node.js)** stack.  
This app allows users to **create**, **edit**, **delete**, and **organize** personal notes with a clean and responsive user interface.

---

## Features

- Create new notes easily  
- View and organize existing notes  
- Edit and update notes in real time  
- Delete notes you no longer need  
- Responsive and user-friendly interface  
- Secure backend with RESTful APIs  

---

## Tech Stacks

### Frontend
- React.js  
- HTML5  
- CSS3  
- Axios  

### Backend
- Node.js  
- Express.js  
- MongoDB (Mongoose ODM)
